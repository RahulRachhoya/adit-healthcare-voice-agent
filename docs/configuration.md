# Configuration reference

Both processes use the same `Settings` class. Local development reads `.env`; hosted services receive environment variables from their private secret settings. Secret values never appear in the readiness response. See [deployment.md](deployment.md) for hosted values and which credentials belong in GitHub Actions.

W = web, A = agent/finalizer, C = operator CLI.

The readiness gate checks all LiveKit/model/storage/Opik groups in both processes. Both use the same local configuration; web does not directly perform every operation, but missing shared configuration intentionally disables admission. Keep `APP_ENV=development`, `COOKIE_SECURE=false` and the loopback allowed hosts for the documented local demonstration. Existing production validation is a guard against insecure exposure, not a requirement to deploy publicly.

Telephone-provider credentials belong in the LiveKit SIP trunk, not in source or the web form. The selected Opik judge uses its built-in free provider and the rule model ID `opik-free-model`. No separate OpenAI or Gemini credential is needed for that judge. `GOOGLE_API_KEY` remains necessary for the application's dialogue and post-call analysis.

The workstation's private `.env` also holds `VOBIZ_SIP_DOMAIN`,
`VOBIZ_SIP_USERNAME`, `VOBIZ_SIP_PASSWORD` and `VOBIZ_CALLER_ID` for provisioning
the LiveKit trunk. The application does not use a Vobiz SDK or need these values
at runtime. The password is secret; caller ID is private. The running Docker
environment is generated from application settings only, excluding these
provisioning fields.

`live_test_verified` is deliberately false in readiness: it is not an automated provider test. Record observed live results in a dated evidence record instead of turning configuration presence into proof.

On September 15, 2026, the Google API rejected `gemini-2.5-flash` for this key because it is no longer available to new users and recommended `gemini-3.6-flash`. The replacement passed actual streaming/tool and structured-analysis checks. The voice worker requests the SDK's default thinking configuration, which selects `minimal` for Gemini 3 Flash. Post-call analysis supplies `Analysis.model_json_schema()` through `response_json_schema`; the legacy schema field rejected `additionalProperties`.

The real call later exposed 3.6 Flash rate-limit/availability failures. Its saved
conversation was successfully analyzed by 3.5 Flash-Lite. Analysis now requests
minimal thinking and can use its own model quota while retaining the same
Google credential and booking/evidence validation.

Save credentials directly in the private `.env`. Replace any credential shared in chat before final use, then recreate both application containers so they load the replacement. Never copy the private file into an image or submission.
